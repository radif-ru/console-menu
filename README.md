## Задача

Программа показывает меню из трёх задач, читает выбор пользователя и
запрашивает нужные числа: считает, сколько билетов выбранной категории можно
купить на бюджет, сколько стоит доставка заказа и сколько ступеней лестницы
построено. После результата программа завершается.

## Принципы реализации

- Вычисляющие функции (`ticketPrice`, `maxTickets`, `deliveryPrice`) только
  возвращают значение, печатающие (`printTicketResult`, `printDelivery`,
  `printSteps`) выводят готовую строку; ввод — только в `main()`.
- Обязательные конструкции на своих местах: `switch` в меню и в цене билета,
  `while` без деления и округления в подсчёте билетов, `for` с `continue` и
  `break` в лестнице, тернарный оператор в расчёте доплаты за километры.
- Тарифы и границы (3000 руб., 3 и 10 км, 200 и 25 руб.) вынесены в константы.
- Ввод через `readline` построчно из асинхронного итератора: работает и в
  терминале, и когда ответы поданы заранее (`printf '1\n2\n2300\n' | node index.js`),
  где `rl.question()` теряет строки.
- Крайние случаи: пустой ответ не превращается в `0`, отрицательное или
  нечисловое значение суммы, расстояния или высоты даёт сообщение
  `нужно ввести неотрицательное число` вместо `NaN` в ответе, закрытый ввод
  (Ctrl+D) не роняет программу.
- Без зависимостей: тесты — встроенный `node:test`, проверки — в GitHub Actions.

## Задачи меню

| № | Задача | Функции | Ключевые конструкции |
|---|--------|---------|----------------------|
| 1 | Билетная касса: категория 1/2/3 — 300/500/900 руб. | `ticketPrice`, `maxTickets`, `printTicketResult` | `switch`, `while` без деления |
| 2 | Доставка: от 3000 руб. или до 3 км — бесплатно, до 10 км — 200 руб., дальше +25 руб./км | `deliveryPrice`, `printDelivery` | условия, тернарный оператор |
| 3 | Лестница: 4-я ступень пропускается, после 10-й — остановка | `printSteps` | `for`, `continue`, `break` |

Неизвестный пункт меню — `такой задачи нет`, неизвестная категория билета —
`неизвестная категория`.

## Запуск

Нужен [Node.js](https://nodejs.org/) 20 или новее:

```bash
node index.js    # или npm start
```

## Проверки

```bash
npm run check    # node --check index.js
npm test         # node --test: функции, граничные значения, сквозные сценарии
```

Те же шаги и сценарии из условия запускаются в
[GitHub Actions](.github/workflows/ci.yml) на каждый push и pull request.
